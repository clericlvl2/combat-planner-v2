# Combat Planner — обновления к vision

Внесено в `docs/vision.md`; при расхождении прав `docs/vision.md`.

Дата: 16.10.2026. Основа: макет по флоу (Styleguide.dc.html).

## Решено

### Player view
- Шапка совпадает с DM CombatHeader, но ничего не редактируется: название, «Round N», кубик эскалации. В Setup вместо раунда «Setup», кубика нет.
- В шапке игрока меню ⋯ с пунктом Change hero. Нижней панели «Playing as» нет.
- Игрок сам бросает и правит инициативу своего героя: поповер с − / + и «Roll d20 +бонус».
- Свой герой: «You» в блоке роли, светло-синий фон, пунктир под инициативой и HP.
- **Видимость (меняет vision):** у героев и союзников видны инициатива, HP и AC / PD / MD. У врагов — инициатива, статус здоровья и состояния.
- Отключённые (Disabled) юниты игрокам не показываются.
- HP-колонка без обводки и полосок, фон в цвет статуса. Тап по своему HP открывает калькулятор: Damage, Heal, Set Temp, без Set Max.
- Раскрывается только своя строка: Conditions, HP History, Note.

### Unit form и пресеты
- Защиты подписаны полностью: Armor Class, Physical Defense, Mental Defense. Числа в одну колонку со степперами.

### Library
- Карточка пресета: HP в блоке роли, AC / PD / MD квадратами, строка тегов. Шеврон раскрывает Edit и ⋯ (Duplicate, Delete).
- **Теги (заменяет «первые 8 + Show all»):** кнопка Tags со счётчиком рядом с поиском, активные теги чипами с Clear. Один лист с чекбоксами для фильтра и для формы. Если тега нет — Create «…», новый тег сразу отмечен.
- **Сортировка:** Newest first, A–Z, By type.

### Combat list
- Карточка боя: цветная точка перед названием, пилюля статуса, раунд и число юнитов. Шеврон раскрывает описание, Edit и ⋯ (Duplicate, Delete).
- **Ручной порядок убран (меняет vision).** Сортировка: Newest first (по умолчанию), Last played, A–Z. Не по умолчанию — кнопка залита и подписана.
- **Новые данные:** для Last played бою нужна дата последнего открытия.

### Combat screen
- Состояния: лист снизу, две колонки A–Z, любые сочетания, применяются по тапу. В шапке только имя юнита.
- Калькулятор HP: действия неактивны, пока не введено число. Урон сначала снимает temp HP, HP может уйти ниже 0. Set Max обрезает текущие HP до нового максимума.
- HP History: внутри калькулятора; из строки юнита — отдельным листом.
- HP до 999; поле HP вмещает −999/999. DM видит 4 сегмента и статус.
- Эскалация 0: пустой пунктирный кубик и «No escalation». DM ставит грань в пикере. Раунд правится от 1 до 99.
- Инициатива: поповер с − / + и «Roll d20 +бонус»; DM — у любого юнита, игрок — у своего героя. Start combat бросает недостающую инициативу и сортирует.
- Если Next turn недоступен, на кнопке написана причина.
- Share: Reissue выпускает новую ссылку и снимает все захваты героев.
- Не больше 99 юнитов в бою.
- Действия юнита в раскрытой строке: Edit и ⋯; в меню Duplicate, Disable / Enable, Save as preset, Release claim, Remove.

### Unit form и пресеты (дополнение)
- From Library: поиск и фильтр Tags, без сортировки.

### Общее
- Toast над нижней панелью, не закрывает Next turn. Disabled и Dead пропускают ход.
- Лимиты текста: имя юнита 40, название боя 80, описание 500, заметка 250, тег 24.
- 8 цветов боя. Статус боя: Setup или Active.
- Языки интерфейса: en, de, es, fr, ja, ru, выбор в Settings.
- Нижние кнопки: высота 58, 28 от краёв экрана, в панелях и листах одинаково.

## Предложено во флоу, нужно подтвердить
- CS-F2: эскалация растёт на 1 со второго раунда автоматически, максимум 6.
- CS-F3: Set Temp заменяет temp HP, а не складывает; Heal не выше Max.
- CS-F6: Duplicate ставит копию под оригиналом с номером «2».
- CL-F4: копия боя — «(copy)», Setup, полные HP, без захватов и без ссылки.
- LB-F4: тег до 24 символов, совпадение без учёта регистра.
- LB-F5: удаление пресета не трогает юнитов в боях.
- LB-F6: Save as preset сохраняет имя, тип, Max HP, защиты, бонус инициативы; без HP, состояний и заметки.
- PV-F1: если героя заняли в момент выбора — тост и кнопка Join неактивна.
- PV-F5: события от DM приходят игроку тостами; отозванная ссылка и удалённый бой — отдельным экраном.
