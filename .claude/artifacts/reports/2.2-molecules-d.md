## Questions

1. `packages/ui/src/molecules/Stepper/Stepper.tsx`: the sign is derived from `min < 0`, so with `LIMITS.initiative` (−9…99) every positive initiative renders as `+15`, `+4`, `+27`; the InitiativePopover page shows `15`, `4`, `27`. Not worked around, because `min={0}` would make negative initiative unreachable by stepping or typing. Proposed fix in Stepper: a `signed` prop that defaults to `min < 0`.
2. `Stepper` takes `value: number` and has no empty state; the page shows `—` for "No initiative yet". InitiativePopover passes `0`, makes the input text transparent while it is not focused and overlays `—`. As a result the spinbutton reports `aria-valuenow="0"` when there is no initiative. Proposed fix in Stepper: `value: number | null` with an empty display.
3. Stepping from no initiative: − / + start from 0 (result −1 / 1). Neither the page nor vision.md says what the starting point is.
4. `onRoll(initiative, roll)`: the brief asks for d20 + bonus. The domain `rollInitiative` action takes the raw roll, so the second argument is the raw d20 (1–20). The first argument is `rolledInitiative(roll, bonus)` from `@combat-planner/domain`, clamped to `LIMITS.initiative`.
5. The brief's "Set calls `onSet(value)`": the page has no Set button. `onSet` fires on every Stepper change (− / +, arrows, typed value on Enter or blur), which maps to `setInitiative`.
6. NoteField is built on `TextArea`. To match the page, the in-field editor overrides TextArea's border, padding, min-height and font size from `NoteField.module.css` (`.field .editor`): the page puts the label and the text inside one bordered box, but TextArea draws its own bordered box with a 15px font.
7. NoteField saves on blur, on Enter, and when `collapsed` turns true while editing. Shift+Enter inserts a newline. An unchanged draft does not call `onChange`. The field is not saved if the parent unmounts it instead of passing `collapsed`.
