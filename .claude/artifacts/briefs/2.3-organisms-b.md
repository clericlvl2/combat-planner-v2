## Acceptance criteria

1. `COMBAT_PLANNER_NO_DOCKER=1 pnpm check`, `pnpm test`, `pnpm storybook:build`
   exit 0; `pnpm exec vp test --project visual -t <Name>` passes for every
   component without `--update`.
2. Each stories file exports exactly the stories `scripts/check-stories.mjs`
   requires for its page (cells and, where the page has a Flow section, the flow
   codes) plus `Extra*` ones, each with a baseline PNG; rendered values match
   the page's script and `renders/<Name>.png` cell by cell; reused atoms and
   molecules are not restyled beyond what the page shows.
3. Each component has at least two `play` stories with `expect(`: the
   callbacks fire with the expected values; the disabled or read-only path does
   not fire; the keyboard and focus behaviour the page or ARIA requires works;
   `Menu` asserts tap on an item calls `onSelect(id)` and closes; Escape and an outside tap close with no selection; arrow keys move through items, disabled items are skipped and never fire; the source gets the ring while open; `Drawer` asserts tap on a section calls `onNavigate` and closes; the current section is marked `aria-current="page"`; Escape and a scrim tap close; focus is trapped while open.
4. Six i18n files per component with identical keys; `check-i18n` passes.
5. One commit `feat(ui): <Name>` per component, each touching only its folder,
   its six i18n files, `allow-same.txt` and its baselines; no comments.
