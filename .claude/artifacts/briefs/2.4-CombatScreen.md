## Units, in this order, one commit each

1. `undoLabel` (`feat(ui): undoLabel`):
   `packages/ui/src/screens/CombatScreen/undoLabel.ts` — the «Undid:
   <action>» text for every undoable action type of the domain action log
   (claim and release are not undoable), with i18n keys in the
   `CombatScreen` namespace (six locales); unit tests in
   `packages/ui/test/screens/undoLabel.test.ts`, one per action type.
2. `CombatScreen` (`feat(ui): CombatScreen`):
   `packages/ui/src/screens/CombatScreen/CombatScreen.tsx`,
   `CombatScreen.module.css`, `CombatScreen.scenarios.ts` (scenario builders
   for the page's roster: Vashti, Brother Tomas, Orc Berserker and the rest
   of the page script), props `combatId`:
   - `CombatHeader` (title, round and escalation popovers in Active, menu
     Undo / Share / Add unit / Restart (Active) / Clear, `undoDisabled` when
     the log has nothing undoable); Setup hides round, die and highlight;
     `TurnBar` Start (disabled «Add a unit first» with no units) or Next turn
     with the next unit and `· round N` on wrap, blocked reasons per vision;
     `EmptyState` with Add unit for an empty roster.
   - `UnitRow` list in the domain order; tap HP → `NumpadSheet` (history
     reversed), then the row flashes through `useHpFlash`; initiative through
     the row's popover; Conditions → `ConditionPicker`; HP History →
     `HpHistory` sheet; Edit → `UnitForm` edit; ⋯ Duplicate, Disable/Enable,
     Save as preset (→ `presets.create`, toast «<name> added to Library»),
     Release claim, Remove (→ `Dialog` confirm; toast «<name> removed» with
     Undo).
   - Add unit → `UnitForm` add with the From Library tab (`usePresets`,
     `useTags`), the `hint` per state, one preset per add; at
     `LIMITS.unitsPerCombat` the toast `Toast.unitCap`.
   - Share → `ShareSheet` with the link from `link.get`; Copy → toast
     `Toast.linkCopied`; Reissue opens `Dialog` «Revoke the link?» and calls
     `link.reissue` only on confirm. Restart and Clear with confirm. Undo
     dispatches `undo` and shows the toast from `undoLabel`.
   - Every change goes through `useCombat().dispatch`; 409 and `network` are
     handled by the hook (toasts); `notFound` on load shows
     `CombatNotFound`, a first load with `network` shows `CantReachServer`.
   - Own Extra stories in `CombatScreen.parts.stories.tsx` are allowed for
     review while building; they are deleted in unit 3.
3. `CombatScreen stories` (`test(ui): CombatScreen stories`):
   `packages/ui/src/screens/CombatScreen/CombatScreen.stories.tsx` with every
   `CS-F*` step the script requires, seeded from `CombatScreen.scenarios.ts`.
