## Acceptance criteria

1. `COMBAT_PLANNER_NO_DOCKER=1 pnpm check`, `pnpm test`, `pnpm storybook:build`
   exit 0; `pnpm exec vp test --project visual -t <Name>` passes for every
   component without `--update`.
2. Each stories file exports exactly the stories `scripts/check-stories.mjs`
   requires for its page (cells and, where the page has a Flow section, the flow
   codes) plus `Extra*` ones, each with a baseline PNG; rendered values match
   the page's script and `renders/<Name>.png` cell by cell; reused atoms are
   not restyled beyond what the page shows.
3. Each component has at least two `play` stories with `expect(`: the
   change/select/click callback fires with the expected value; the disabled or
   read-only path does not fire; the keyboard path the page or ARIA requires
   works (arrows in segmented and radio groups, Space/Enter on rows, Escape to
   close a popover); `Toast` asserts the action button fires `onAction`, the toast hides after 4 s (8 s with an action) using fake timers or an injected `duration` and that `motion: 'off'` fires at once; `EmptyState` asserts the action fires and renders without an action.
4. Six i18n files per component with identical keys; `check-i18n` passes.
5. One commit `feat(ui): <Name>` per component, each touching only its folder,
   its six i18n files, `allow-same.txt` and its baselines; no comments.
